# [MIETVERTRAG: PFLICHTEN & GELD]
* **Kaution (OR 257e):** Wohnräume max. 3 Monatszinse. Muss auf Sperrkonto lautend auf Mietername[cite: 1, 8].
* **Nebenkosten (OR 257a):** Müssen nur bezahlt werden, wenn vertraglich vereinbart. Akonto vs. Pauschal[cite: 1, 8].
* **Missbräuchlicher Mietzins (OR 269):** Wenn Vermieter "übersetzten Ertrag" erzielt. Mieter kann Herabsetzung bei Schlichtungsbehörde verlangen[cite: 1, 8].
* **Untermiete (OR 262):** Mieter darf untervermieten. Vermieter darf nur verweigern wenn: 
  1. Mieter verweigert Nennung der Bedingungen, 
  2. Bedingungen sind missbräuchlich (zu teuer), 
  3. Vermieter hat wesentliche Nachteile[cite: 1, 8].
